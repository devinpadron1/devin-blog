# The Fundamentals

Theres a lot of AI noise which has led me to reflect on what the fundamentals are.

Fundamentals are things that are true across time
Fundamentals are true across all tech stacks
Fundamentals are foundational to a field
Fundamentals are stable across time
Fundamentals (mastery of them) lead to more creativity 
Fundamentals (mastery of them) lead to more grounded decision making 
Fundamentals aren't required to get a job, but required to be great 

What are some of the fundamentals in my profession?
Data Structures & Algorithms: applications need to be efficient
Operating Systems: applications need resources
Databases: applications need to store information 
Networking: applications need to communicate with external sources 
Security: applications need to be secure 

Note to self: no matter how loud things get, don't skimp on the fundamentals.
