# Focus 

Focus is my ultimate constraint.

Social media is well known to drain focus. The infinite scrolling, slot machine mechanics, short form content, etc.

Agentic coding has similar properties. Start one agent. Get restless. Start 2 more. Get an idea. Start another. Every thread, every prompt is another pull of the lever. Pretty soon, you're spending your day juggling multiple agents at a time, shifting focus from thread to thread.

There's no going back from this work mode. But there is still value in carving out a slice of the day to focus on one thing - whether writing or coding. One problem, zero distractions, and if you really need an LLM - one thread for quick prompts.

Focus is all you need.
